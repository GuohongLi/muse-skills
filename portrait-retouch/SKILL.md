# Portrait Retouch（人像修图）

## Purpose
按专业人像修图流程修图，附带人像自动二次构图：一张原图可按不同景别裁出多张构图版本。默认风格为海马体/韩式清新风（高调柔光、清透淡妆、皮肤通透干净），用户可指定日系、欧美、古风。触发词：用户说「人像修图」并附上人像照片。

## 风格选项（修图前确认，默认海马体）
- **海马体/韩式（默认）**：高调柔光、均匀通透；清透淡妆感，水光肌底妆；肤色干净红润不假白；背景干净简洁；低对比、整体明亮。
- **日系清新**：低对比、高明度、略带青蓝调；空气感、自然情绪；肤色通透红润；减法构图、大量留白。
- **欧美**：轮廓立体、对比稍强；健康小麦色或暖调肤色；眉眼深邃；背景可带氛围感。
- **古风/中式**：雾面质感底妆、黑发适配；大气复古；弱化腮红、红唇点缀；影调沉稳。

## Workflow
1. **诊断**：先看画质——对焦是否在眼睛上（100% 放大眼睛必须清晰）、皮肤瑕疵（痘印/斑点/眼袋/泪沟/法令纹）、肤色问题（暗沉/偏黄/偏红/脸与脖子色差）、头发碎发、牙齿偏黄、曝光（面部死白或死黑）、噪点、背景杂物抢戏。再看构图——景别是否合适（特写/半身/全身）、眼睛是否在上三分线、头顶留白是否得当、是否在关节处裁切（脚踝/膝盖/手腕/肘部）、视线方向是否局促、人物是否居中呆板。
2. **定二次构图方案**：根据原图定 1–4 个版本，每个版本明确目标画幅（人像常用竖画幅 4:5、3:2、1:1）、裁掉什么/保留什么、眼睛放在哪个三分点、留白安排。常用版本模板：
   - **脸部特写版**：向面部裁近，眼睛放上三分线交叉点，fill the frame，突出眼神；不贴发际线裁头，头顶留一线呼吸感；
   - **半身版**：胸上或腰上取景，人物放左下/右下三分点，视线方向多留白；避开关节处裁切；
   - **环境人像版**：保留有氛围的环境，人物占画面 1/3 左右，用环境讲故事；背景杂乱则交代虚化；
   - **留白版**：人物偏向一侧，大面积干净负空间，适合做封面/文案。
   海马体构图偏好：干净背景优先，半身和特写为主，眼睛永远是视觉中心放上三分线，头顶留白适度不压抑，整体明亮通透。
   构图铁律：眼睛 100% 清晰且放上三分线；不在关节处裁；不贴发际线切头；视线/身体朝向多留空间；少即是多，不裁过头。
   若原图构图已很好可只出 1 个版本；用户说"多裁几张"或一人多可用景别时出 2–4 个版本。
3. **定修图指令**：按专业人像流程顺序组织技术指令——
   校正（水平/裁剪）→ 曝光（面部提亮找回细节，高光不死白）→ 白平衡/肤色（去偏色，脸与脖子/手臂肤色统一）→ 瑕疵修复（痘印斑点去除，痣和美人痣保留）→ 皮肤修饰（保留毛孔纹理的柔化，dodge & burn 修光影：鼻梁额头颧骨提亮、脸颊鼻翼压暗，立体感自然）→ 五官精修（眼睛：眼白轻微提亮、瞳孔加深提神、眼袋泪沟柔化但留自然痕迹；鼻子：鼻翼两侧压暗、鼻梁提亮；嘴唇：唇色红润自然）→ 头发（碎发清理，发丝锐化）→ 形体（仅在需要时微调，液化分寸极小）→ 背景虚化或简化（如需要）→ 影调统一（按选定风格）。
   只写技术指令，不加风格化描述词；风格差异只通过影调/肤色/对比度的技术参数体现。
4. **执行**：每个构图版本独立调用一次 `media.generate_image`（单次回复最多 4 张），prompt 结构：
   - 第一行：用户原话（「人像修图」），原样保留不改写
   - `Context:` 块：先写本版本的二次构图方案（目标画幅、裁剪取舍、眼睛位置、留白），再写选定的风格（海马体/日系/欧美/古风），最后按第 3 步顺序列修图技术指令
   - 附上原图作为 image 输入
   - `name` 用描述性英文 slug（如 `portrait-closeup` / `-halfbody` / `-environment`）
5. **验图**：100% 放大检查眼睛锐度（必须清晰有神）、皮肤纹理（有毛孔无塑料感）、肤色过渡（脸脖一致无断层）、边缘紫边、背景虚化过渡自然；确认无过度液化、无换脸感、无后期痕迹。没问题再进入下一步。
6. **分辨率检查与放大**：检查每个成品的最长边，若不足 2560px（2K）则做一次放大：优先用 Real-ESRGAN（`~/workspace/.venv-upscale/bin/python ~/workspace/.venv-upscale/realesrgan_pure.py <输入> <输出> 256`，纯 torch 无需 torchvision；模型在 `~/.cache/realesrgan/RealESRGAN_x4plus.pth`），不可用时退回 PIL LANCZOS 2x 插值放大。放大后快速复验无异常再交付。
7. **交付**：简述诊断出的问题，说明每个版本的构图思路（一句话），注明所用风格，如实说明是否做过放大，附上所有成图（每张 `![描述](sandbox://workspace/...)` 独立一行）。

## Operating Rules（人像硬规则）
1. 保留皮肤真实纹理：柔化只做"刚好够"的量，毛孔和细纹必须可见，绝不做塑料皮。
2. 眼睛 100% 清晰：焦点在眼睛上，眼白干净、瞳孔有神；眼袋泪沟只做柔化，保留自然痕迹。
3. 不凭空改五官：不换脸型、不放大眼睛、不改鼻梁高度；液化只做极小幅度形体微调，动完看不出动过。特写/半身版放大脸部时必须加指令"严格保持原图面部五官比例、脸型、五官位置一致，不拉宽不压扁不变形"（生成式重绘容易把脸画宽）。
4. 肤色统一：脸、脖子、手臂无色差断层；肤色干净红润，不假白、不荧光。
5. 痣和美人痣默认保留，只去痘印斑点等临时瑕疵；碎发清理但不改变发型。
6. 夜景/暗光人像保留氛围感，暗部可提亮但不准修成白天；降噪适度不涂抹。
7. 二次构图只做裁剪取舍，不准凭空添加原图没有的元素；背景杂物优先裁剪去掉。
8. 一张原图最多出 4 个构图版本；每个版本必须构图思路不同，不准换汤不换药。
9. 分辨率红线：成品最长边不足 2560px（2K）时必须做一次放大（Real-ESRGAN 优先，PIL LANCZOS 2x 兜底），用户原图不足 2K 也一样处理。

## 诊断模板（第 1 步直接套用）
- 眼睛：对焦是否在眼睛上 / 眼神是否有神 / 眼袋泪沟程度
- 皮肤：痘印斑点位置 / 暗沉或偏色 / 毛孔纹理现状 / 脸脖色差
- 五官：是否需要立体感塑造（鼻影/唇色）/ 牙齿是否偏黄
- 头发：碎发 / 发丝光泽
- 曝光：面部是否死白或死黑 / 背景是否过曝抢戏
- 构图：当前景别 / 眼睛位置 / 头顶留白 / 是否裁在关节处 / 视线方向空间 / 背景干扰物
